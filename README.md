# InkaTraces · Panel de avances

Panel estático (HTML + CSS + JS) para presentar al cliente el estado de **SEO**, **GEO** (asistentes de IA) y **medición** (Search Console / etiquetas).

- Tema claro por defecto, oscuro opcional
- Checklist con progreso e historial (se guarda en el navegador)
- Identidad visual alineada a [inkatraces.com](https://inkatraces.com/)

## Local

Abrir `index.html` o servir la carpeta.
